Upload instructions:

1. Copy about.html into the root of your website repo, beside index.html.
2. Open your existing style.css.
3. Paste the contents of style-additions.css at the very bottom of style.css.
4. Commit and push:

   git add .
   git commit -m "Add about page"
   git push

The page will be available at:

https://southernskiesagritech.com.au/about.html

Note:
The page currently includes:
<meta name="robots" content="noindex, nofollow" />

Remove that line when you are ready for Google to index the site.
